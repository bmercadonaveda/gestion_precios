Cargar datos desde Excel

Sube un archivo .xlsx con la misma estructura del reporte "Descuentos JPRE" (columnas: des_prod, desc_planta, Fecha_venta, Galones, Ingreso, Pond.PL, entre otras). El dashboard completo (mapa, KPIs, filtros y evolución de precios) se reconstruye automáticamente con la información del archivo cargado, reemplazando los datos actuales.

Al aplicar el archivo, además de actualizarse en tu pantalla, se envía a la base de datos compartida (Google Sheets). Así, cualquier persona que abra este dashboard verá la misma información — no hace falta que cada uno suba el Excel por su cuenta.
